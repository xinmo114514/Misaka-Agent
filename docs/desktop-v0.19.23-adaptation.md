2. **共享主题校验**：将可选的桌面颜色和图表调色板补入 Python 源 schema 及类型声明，重新生成主题 JSON schema。保留原有主题颜色，修正手工生成文件中不存在的 `colorValue` 引用，统一使用 `ColorValue`，继续拒绝未知字段和不合法值。
