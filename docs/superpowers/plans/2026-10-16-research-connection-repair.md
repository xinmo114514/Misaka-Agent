# 通用化修复研究启动连接错误

## 目标与约束

以当前含未提交改动的工作区为基线，修复模型连接失败被误报为提交失败。兼容直连、用户配置的任意代理端口、NO_PROXY 和不同供应商。保留用户网络配置、角色模型、原始课题及请求幂等；不自动重发真实课题，不切换代理/系统路由/模型。

## Task 1: 模型网络路由

- 新增请求级纯路由解析：无代理直连，按实际目标选择显式代理，NO_PROXY 命中直连；支持 HTTP/HTTPS/SOCKS、本机/远程/IPv6/认证和协议标准默认端口。请求级环境优先，大小写与显式空值按现有约定处理。
- Codex WS/SSE 路由一致，HTTPX 关闭隐式系统代理发现但保留 CA 配置。兼容普通 OpenAI-compatible 模型客户端的请求级网络配置。
- 代理失败保留路由；解析错误明确返回；补齐 SOCKS 依赖。连接诊断仅对实际路由进行无凭证 TCP 检查，不扫描端口，不发送模型请求。
- 先写失败测试，覆盖任意/动态端口、IPv6、NO_PROXY、格式错误、显式空值、代理认证脱敏及 WS/SSE。

## Task 2: 招募错误与持久化

- 移除 Python 代理清理和 Electron 普通桥接代理删除，保留普通/研究入口的一致环境。
- 招募尝试独立计数并绑定新终态，模型错误先于成员数量检查；超时/取消先 abort 并等待 idle，隔离迟到回包。
- ResearchInputError 和 ACK 增加可选 errorDetails，包含角色、模型、路由、脱敏原始错误。按实际证据区分直连、代理、DNS、TLS、鉴权、额度和上游错误。
- 独立 desktop-recruitment 启动记录保存原始 envelope 和尝试状态，不写入 delivery receipt。历史投影恢复失败原课题、参数和重试状态，抑制与已发布原生用户条目的重复。
- 诊断命令检查当前主控的真实 endpoint/有效环境，不收集课题或凭证。
- 先补回归，再实现；修复超时测试的主控模型/凭证隔离。

## Task 3: 前端错误与重试

- 错误详情跨类型、bridge、store、历史和消息组件保持；显示中文短摘要及可展开原始详情、检查连接、重试启动。
- 诊断状态按会话/stream 隔离，防重复点击；TCP 成功仅标记网络端口可达，显示环境变更需要重启应用。
- 重试复用同请求、根会话和原始配置。无 Run 使用重试启动；历史缺少完整参数时引导确认配置后新建提交。
- 先补前端失败测试，再实现，保持普通聊天及工作台兼容。

## Task 4: 集成验收

- 后端针对路由/招募/receipt/原课题重试回归，前端全量 Vitest、类型检查、构建。
- 本地可控模型及代理运行隔离 Electron 端到端：直连成功、任意端口代理成功、连接失败真实详情、恢复同课题、原输入与 Run 唯一。
- 独立审查改动后修正问题，最终报告真实验证结果与环境限制。
