## Compatibility & Un-Green Fixes

1. **Windows Subprocess Import Safety (`tests/posix.py` -> `tests/posix_test_support.py`)**
   - `tests/posix.py` in the test root was shadowing Python standard library imports (`import posixpath` -> `tests/posix.py` -> `pytest` -> `tempfile.py`), causing circular import crashes (`AttributeError: tempfile has no attribute TemporaryDirectory`) in all spawned child ACP agents (`tests/test_ally_card.py`).
   - Renamed `tests/posix.py` to `tests/posix_test_support.py` and updated all referencing test files.
   - Added `tests/test_subprocess_import_safety.py` regression test.
   - Result: all 17 ACP / ally tests pass without failure.

2. **Windows DDGS Worker Termination (`misaka/core/web/backends/ddgs.py`)**
   - On Windows, launching Python through a virtualenv wrapper results in a launcher process spawning the actual Python interpreter. Terminating only the launcher left the child worker alive as an orphan.
   - Updated `_terminate_and_reap` to terminate the owned process tree on Windows while keeping asyncio's process waiter intact.
   - Added `test_ddgs_cancellation_reaps_worker_without_touching_sibling` regression in `tests/web/test_web_timeouts.py`.

3. **PDF OCR Routing Reread Metadata (`misaka/core/documents/index.py`)**
   - Successful PDF visual routing was leaving `reread_put_off` uncleared when OCR was pending, causing stale retry accounting.
   - Cleared visual retry metadata independently of OCR availability while preserving deferred OCR status.
   - Updated `tests/test_pdf_ocr_routing.py` regression.

4. **Extension Boundary Decoupling (`misaka/desktop_research/auxiliary.py`)**
   - Desktop research was directly inspecting and importing `misaka.extensions.misaka_lcm`, violating `test_extension_boundary.py`.
   - Replaced package-specific strings and direct imports with extension-declared `desktop_research_factory` protocol.
   - Updated `tests/test_desktop_team_auxiliary.py` and `tests/test_extension_boundary.py` pass cleanly.

5. **Windows Path and Mode Assertions**
   - `test_auth_storage_links.py`: used `os.path.samefile` to handle Windows `\?\` long path prefixes on symlinks.
   - `test_web_debug.py`: conditioned POSIX permission bit (`0o700` / `0o600`) assertions on `os.name != "nt"` since Windows ACLs manage directory privacy.
   - `test_web_finish_browser.py`: normalized path separators with `Path.as_posix()` for `.cmd` check.

6. **Test Flakiness & Race Conditions**
   - `test_web_audit_regressions.py`: replaced arbitrary sleeps with event-based synchronization in cache race test.
   - `test_web_extract_tool.py`: synchronized abort signal with vendor call entry event.
   - `test_subagent_native_startup.py`: separated child process startup window from request completion window on Windows, avoiding premature timeouts.
