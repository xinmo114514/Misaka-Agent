## 最终行为

- 使用上游新版供应商、鉴权、模型运行时和 `modes/interactive` TUI；Python 包与桌面包版本均为 0.19.18。
- 桌面 JSONL 桥接适配模型和供应商枚举、模型切换、主题、附件、API Key 保存/删除及会话导出；凭证写入等待原生异步存储完成后才 ACK。
- 研究读取使用图投影获得驱动租约，迁移至 `research_cards`、`research_execution` 和图日志；保留请求身份、消息重放、研究主控、停止收尾和最终报告交付。
- 普通聊天、研究主控及 worker 使用同一请求级代理策略。Anthropic SDK 必须使用显式 HTTP transport，避免其默认客户端在 `trust_env=False` 时仍挂载环境代理。
- 卡片续聊通过 `--say-file` 传递长提示，并在退出/失败后清理。原生咨询保留卡片完成状态与当前代际；未交付邮件崩溃后自动恢复，最多自动重试两次，已确认输入不重放。
- 卡片证据事件携带当前 claim lock，使当前尝试的完成校验能够读取已提交证据。保留上游中文程序输出容错和截断回复续写。

## Windows 主机限制

最终桌面选集排除：独立 CLI 冒烟（另行单独通过）、Node 服务桥接子进程测试、两个强杀 worker 测试、原生子代理子进程测试。后三类在本机复现 `CreateProcess: WinError 5`，尚不能声明通过。TUI/发布选集另排除 `where` 成功查找路径测试：该测试通过 Python 子进程模拟原生命令，本机返回了 None 而非路径，未将其认定为通过；需在 CI 复验。没有放宽生产权限或改写测试来把这些失败当作通过。

卡片咨询崩溃恢复另有不依赖 OS 子进程的定时恢复、释放前后崩溃、交付去重及重试上限回归；真实生产 Electron 已执行研究 worker。后续 CI 应在允许子进程的 Windows 环境运行上述排除项。
