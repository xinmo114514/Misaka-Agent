# 桌面端网络与代理设置：实现及验证

日期：2026-10-18。保留 `codex/research-tiling-workspace` 上原有未提交改动；本次未暂存、提交或推送。

## 使用方式

打开 **设置 → 网络与代理**：

- 开启 **使用代理**：选择 HTTP、HTTPS、SOCKS5 或 SOCKS5h，填写服务器及实际端口，然后点击 **保存代理设置**。不预设代理软件端口。
- 关闭开关：由用户选择 **直接连接** 或 **沿用环境代理**，保存后生效。尚未保存过此配置的安装默认沿用环境，保持已有行为。
- 修改尚未保存时显示提示；保存与连接检查均有进行中、成功及错误反馈。读取失败可独立重试，旧路由不冒充当前路由。
- **检查连接**针对草稿或已保存配置做 TCP 检查，不保存草稿、不发送课题或凭证，也不把 TCP 可达当成模型推理、鉴权或额度正常。

配置原子保存到全局 `network.proxy`，不改系统代理或 `.env`。普通聊天、Last Order、Sisters 的新模型请求读取同一配置；已发出的请求保留自己的环境快照。修改设置不自动重发课题或恢复研究。

## 接通的链路

- 共享策略区分自定义、强制直连与环境路由，覆盖大小写代理变量，保留有效 `NO_PROXY`、CA 及供应商其他环境字段。异常配置明确报错，不猜端口或静默换路由。
- 原生模型注册表在请求准入处固定配置；需要异步鉴权的入口在鉴权合并后应用策略，保留凭证级环境优先级。复制调用者环境，避免鉴权等待期间的外部修改改变请求路由。
- HTTPX 模型传输、Codex WS/SSE、原生 OAuth HTTP 和模型列表查询均接通；“测试模型连接”恢复完整原生鉴权、实际 endpoint 和环境传递。
- 研究错误保留真实失败请求的路由；新的显式连接检查使用当前配置，不沿用旧失败快照。
- Bedrock 按 SDK 实际解析出的 endpoint 判断绕过列表；Vertex 对齐 global、us/eu 多区域及普通区域地址；Pi 注入传输保留调用方所有权并关闭自建资源。
- Google 可选依赖下限调整为已验证的 `google-genai>=2.19.0`；离线更新锁文件，没有声称这是相关接口最早出现的版本。

新增 JSONL 命令：`get_proxy_settings`、`set_proxy_settings {settings}`、`check_proxy_connection {settings?}`。沿用原有 Electron 转发与 ACK 提交边界。

### 权限相关验证边界

较宽的后端组合首次执行得到 501 通过、6 失败、3 跳过。其中两项旧测试仍 monkeypatch 已移除的“静默清理代理”函数，已改为直接验证环境代理保留，单独 **14 通过**。

另四项既有用例涉及 Windows 符号链接、pytest 内 CLI 子进程或通用原生子 Agent 创建；在本机返回 `WinError 5`，最终选集中显式排除，没有通过改系统权限、恢复代理清理代码或放宽生产逻辑消除错误。三项跳过包括两项 pytest 内新解释器启动权限限制，以及一项 Windows 缺少 FIFO 的既有条件跳过。新导入顺序测试使用活动虚拟环境解释器，只有 Windows 拒绝创建进程时才跳过，真实导入错误仍失败。

相同入口的顶层 CLI / 导入检查以及生产 Electron 研究工作进程另行成功；这不等于上述四项 pytest 用例已经通过。早期未限制 worker 的前端运行发生 IPC worker 退出，最终受限并发的全量运行已重新通过。

## 范围与限制

- Web、搜索、下载、浏览器、MCP、终端工具保持各自网络策略，不将此设置描述成全系统代理。
- Bedrock SDK 的 HTTP(S) 代理及 CA 文件已支持；所选 SOCKS 或仅 CA 目录配置会得到明确能力错误。HTTPX 适配器支持 SOCKS5/5h 和 CA 文件／目录。
- Google ADC、AWS SDK 内部凭证链的刷新／元数据请求仍遵循各自 SDK 配置；接通的是 MISAKA 自有 OAuth 登录／刷新 HTTP 路径。
- 没有修改用户真实代理配置、系统网络、角色模型、课题或工作区，没有调用远端模型，也没有自动重发真实课题。代理服务自身仍需按用户填写的地址保持运行。
